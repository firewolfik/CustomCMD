# CustomCommand

Лёгкий, быстрый и безопасный плагин для создания кастомных команд на серверах Minecraft (Paper / Spigot 1.21+).

> **Примечание:** Данный проект является переписанным форком плагина **MyCommand**.
> Из него был полностью вырезан устаревший код (1.8–1.12), удалены уязвимости (включая опасный `RUN_AS_OPERATOR` и `/mycmd-runas`), переработана архитектура под современный Paper API (1.21+), добавлена нативная поддержка MiniMessage и звуков.

---

## Особенности

- **Поддержка современных форматов текста**: MiniMessage теги (`<gradient>`, `<rainbow>`, `<click>`, `<hover>`), HEX-цвета (`&#rrggbb` / `<#rrggbb>`) и классические `&`-коды.
- **Безопасность**:
  - Никакой выдачи временного OP игрокам (`player.setOp(true)` исключен).
  - Консольные команды безопасно выполняются через `Bukkit.getConsoleSender()`.
  - Защита от многострочных инъекций аргументов.
- **Типы команд**:
  - `TEXT` — сообщение игроку в чат
  - `BROADCAST` — оповещение всем игрокам
  - `RUN_COMMAND` — выполнение команды от лица игрока
  - `RUN_CONSOLE` — выполнение команды от консоли
  - `ACTION_BAR` — сообщение в экшнбар
  - `TITLE` — полноэкранный Title и Subtitle
  - `ALIAS` — перенаправление на другую команду
- **Гибкие звуки**: поддержка звуков как для команды целиком (`sound: ENTITY_PLAYER_LEVELUP 1.0 1.0`), так и пошагово в строках через `$sound:...$`.
- **Задержки шагов**: выполнение с задержками через `$delay:СЕКУНДЫ$`.
- **Кулдауны и аргументы**: настройка задержек между вызовами, минимальное число аргументов, проверка прав.
- **Интеграция**: PlaceholderAPI и Vault (платные команды).
- **Динамическая регистрация**: команды регистрируются в CommandMap ядра на лету и корректно обновляются при `/cc reload` без перезапуска сервера.

---

## Команды плагина

- `/customcommand reload` (или `/cc rl`) — перезагрузка конфигурации и команд.
- `/customcommand list` (или `/cc list`) — количество загруженных команд.
- `/customcommand help` — справка.

---

## Пример конфигурации команды

Создавайте `.yml` файлы в папке `plugins/CustomCommand/commands/`:

```yaml
rules:
  command: /rules
  aliases:
    - /правила
  type: TEXT
  lines:
    - "<gold><bold>Правила сервера:</bold></gold>"
    - "<yellow>1.</yellow> <gray>Уважайте игроков и администрацию.</gray>"
    - "<yellow>2.</yellow> <gray>Запрещены читы и стороннее ПО.</gray>"
    - "<click:open_url:'https://myserver.net'><aqua>Наш сайт: myserver.net</aqua></click>"
  permission: "server.rules"
  permission_message: "<red>У вас нет прав на эту команду!</red>"
  cooldown: 5
  cooldown_message: "<red>Подождите %time% сек. перед повторным вводом!</red>"
  sound: ENTITY_EXPERIENCE_ORB_PICKUP 1.0 1.0
```

## Сборка проекта

Требуется **Java 21** и **Maven**:

```bash
mvn clean package
```

Собранный jar-файл появится в папке `target/`.
