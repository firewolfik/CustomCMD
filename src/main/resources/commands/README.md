# CustomCMD - Документация по созданию команд

Файлы с командами хранятся в папке `plugins/CustomCMD/commands/`.
Можно создавать любое количество `.yml` файлов. Все команды будут автоматически загружены.

## Пример конфигурации команды

```yaml
rules:
  command: /rules
  aliases:
    - /правила
  type: TEXT
  lines:
    - "<gold><bold>Правила сервера:</bold></gold>"
    - "<yellow>1.</yellow> <gray>Уважайте игроков и администрацию.</gray>"
    - "<yellow>2.</yellow> <gray>Запрещены читы и стороннее ПО.</gray>"
  permission: "server.rules"
  permission_message: "<red>У вас нет прав на эту команду!</red>"
  cooldown: 5
  cooldown_message: "<red>Подождите %time% сек. перед повторным вводом!</red>"
  sound: ENTITY_EXPERIENCE_ORB_PICKUP 1.0 1.0
```

## Типы команд (type)

| Тип | Описание |
|---|---|
| `TEXT` | Отправляет сообщение в чат игроку |
| `BROADCAST` | Отправляет сообщение всем игрокам на сервере |
| `RUN_COMMAND` | Выполняет команду от имени игрока |
| `RUN_CONSOLE` | Выполняет команду от имени консоли |
| `ACTION_BAR` | Отправляет сообщение в Actionbar |
| `TITLE` | Отправляет Title и Subtitle на экран |
| `ALIAS` | Перенаправляет на другую команду с передачей аргументов |

## Параметры команды

- `command` — вызываемая команда (с `/` или без).
- `aliases` — список альтернативных команд.
- `type` — тип команды (по умолчанию `TEXT`).
- `lines` — список строк текста или команд для выполнения.
- `permission` — право для использования команды.
- `permission_message` — сообщение при отсутствии прав.
- `cooldown` — задержка в секундах между использованиями.
- `cooldown_message` — сообщение во время задержки (`%time%` — остаток секунд).
- `min_args` — минимальное количество аргументов.
- `min_args_message` — сообщение, если передано меньше аргументов.
- `cost` — цена выполнения (требуется Vault).
- `cost_message` — сообщение при нехватке денег (`%cost%` — стоимость).
- `sound` — звук при вызове (например: `ENTITY_PLAYER_LEVELUP 1.0 1.0`).
- `only_player` — запретить вызов из консоли (`true` / `false`).
- `tab_completer` — список вариантов автодополнения (Tab).

### Параметры для TITLE:
- `title` — основной заголовок.
- `subtitle` — подзаголовок.
- `fade_in` — время появления в тиках (по умолчанию 10).
- `stay` — время отображения в тиках (по умолчанию 40).
- `fade_out` — время исчезновения в тиках (по умолчанию 10).

### Параметры для ACTION_BAR:
- `actionbar` — текст сообщения над хотбаром.

### Параметры для ALIAS:
- `alias` — целевая команда (например: `/spawn`).

## Форматирование текста

Поддерживаются:
- **MiniMessage**: `<red>`, `<green>`, `<bold>`, `<italic>`, `<rainbow>`, `<gradient:#ff8a00:#e52e71>Текст</gradient>`, клики и наведения.
- **HEX-цвета**: `<#ff0000>`, `&#ff0000`, `#ff0000`.
- **Классические коды**: `&a`, `&c`, `&e`, `&l` и т.д.

## Звуки и задержки в строках

Внутри строк `lines` (для `RUN_CONSOLE`, `RUN_COMMAND`, `TEXT`, `BROADCAST`) можно использовать префиксы:
- `$delay:СЕКУНДЫ$` — задержка перед выполнением этой строки.
- `$sound:ИМЯ_ЗВУКА:ГРОМКОСТЬ:ВЫСОТА$` — проигрывание звука игроку.

Пример:
```yaml
timer:
  command: /timer
  type: RUN_CONSOLE
  lines:
    - "$sound:BLOCK_NOTE_BLOCK_PLING:1.0:0.5$title %player% title {\"text\":\"3\"}"
    - "$delay:1$$sound:BLOCK_NOTE_BLOCK_PLING:1.0:0.7$title %player% title {\"text\":\"2\"}"
    - "$delay:1$$sound:BLOCK_NOTE_BLOCK_PLING:1.0:1.0$title %player% title {\"text\":\"1\"}"
    - "$delay:1$$sound:ENTITY_PLAYER_LEVELUP:1.0:1.0$title %player% title {\"text\":\"СТАРТ!\"}"
```

## Переменные

- `%player%` — ник игрока.
- `%player_uuid%` — UUID игрока.
- `%world%` — мир игрока.
- `%args%` — все введенные аргументы через пробел.
- `%arg1%`, `%arg2%` ... `%arg20%` — аргумент по номеру.
- `%args_length%` — количество аргументов.
- Любые плейсхолдеры PlaceholderAPI (если плагин установлен).
